# Travodo

Travodo는 여행을 여행 전, 여행 중, 여행 후의 세 단계로 나누어 위치 공유, 계획 관리, 커뮤니티 등의 기능을 제공하는 여행 앱입니다.

## 주요 기능

- 여행 생성 및 초대 코드로 참여
- 여행 캘린더와 진행 예정·진행 중·완료 여행 관리
- 공동 준비물, 개인 준비물, 필수 할 일 체크리스트
- 여행 일정과 메모 관리
- 지도에서 여행 장소 및 멤버 위치 확인
- 여행 후기 커뮤니티 게시글, 댓글, 좋아요, 북마크
- 이메일 및 카카오 로그인

## 기술 스택

- React Native, Expo
- JavaScript
- React Navigation
- Axios
- AsyncStorage
- Kakao Login
- React Native Maps

## 실행 방법

### 요구 사항

- Node.js 및 npm
- iOS Simulator 또는 Android Emulator
- Expo 개발 환경

### 설치 및 실행

```bash
git clone <저장소 주소>
cd Travodo-Frontend-2
npm install
npm start
```
